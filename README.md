# AI Tic Tac Toe
AI-Tic-Tac-Toe is an unbeatable game powered by a C-based Minimax engine. This project offers a highly performant AI capable of playing standard 3x3 games and a more challenging 4x4 variant.

You can download the latest pre-built versions of the application from the Releases section of the repository:
👉 [Download Pre-built Assets](https://github.com/zane0703/AI-Tic-Tac-Toe/releases)
- **Windows:** Tic-Tac-Toe-Windows-x86-64.exe (Tested on Windows 11).
- **Android:** Tic-Tac-Toe-android-arm64.apk (Tested on Android 16).
- **Web:** Play directly in your browser via [GitHub Pages](https://zane0703.github.io/AI-Tic-Tac-Toe/).
## ✨ Key Features
- Unbeatable Minimax AI: Ensures the AI plays optimally in all modes.
- Multi-threading: Recent updates added multi-threading support to further improve engine performance.
- Difficulty Control: Includes a Depth Limit setting, allowing players to adjust how many moves ahead the AI calculates.
- Cross-Platform: Maintained across dedicated branches for Web (WebAssembly) and Desktop (Qt).
## ⚠️ Performance Warning
The 4x4 Tic-Tac-Toe mode is very demanding and may consume 100% of your CPU, especially if you increase the Depth Limit in the game settings.

## 🛠️ Technical Stack
- Core Logic: C.
- Desktop GUI: C++ and Qt6 (developed in Qt Creator).
- Web Engine: WebAssembly (compiled via Emscripten).
- Build System: CMake.
